# 🍄 超级玛丽 HTML5 游戏

一个用纯 HTML5 Canvas + JavaScript 实现的超级玛丽风格平台跳跃游戏。

## 🎮 玩法说明

- **⬅ ➡ 方向键** 或 **A/D** — 左右移动
- **⬆ 空格键** 或 **W** — 跳跃
- **P** — 暂停/继续

## ✨ 游戏特性

- 🏃 马里奥角色动画（跑步、跳跃）
- 👾 Goomba 敌人 AI（巡逻、可踩踏消灭）
- 💰 金币收集系统
- 🟢 管道障碍物
- 🧱 砖块和问号方块平台
- 🏁 旗杆终点
- ❤️ 生命系统和无敌闪烁
- ⏱️ 倒计时机制
- ☁️ 视差滚动背景（云、山、灌木）
- 📊 实时分数、金币、生命、时间显示

## 🚀 运行方式

直接用浏览器打开 \index.html\ 即可游玩，无需任何服务器或依赖。

\\\
game/super_mario/
├── index.html   # 游戏页面
└── game.js      # 游戏引擎
\\\

## 🛠️ 技术栈

- HTML5 Canvas 2D
- 原生 JavaScript（ES6+）
- 无外部依赖
