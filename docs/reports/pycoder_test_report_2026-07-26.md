### 2.3 第一轮测试发现的问题

#### ❌ 已发现的问题 (P0 - 阻塞性)

1. **API 路径不一致**
   - 测试脚本中使用的 `/api/v2/memory/*`、`/api/v2/evolution/*` 等路径返回 404
   - 实际路径为 `/api/memory/*`、`/api/v2/evolution/core/*`
   - **影响**: API 文档与实现可能存在不一致
   - **优先级**: 高

2. **前端启动失败**
   - Electron 启动时遇到 GPU 缓存权限问题
   - 错误: `Unable to move the cache: 拒绝访问 (0x5)`
   - **影响**: 无法进行 UI 端到端测试
   - **优先级**: 阻塞

#### ⚠️ 警告 (P1 - 需关注)

3. **能力 ID 命名不一致**
   - 通过 `POST /api/v2/capabilities/{id}/invoke` 调用失败
   - 需要确认实际的能力调用 API 路径

4. **OpenAPI 端点 514 个**
   - 大量端点，需要分批测试

## 四、修复建议

### 4.1 Electron 启动问题修复

**问题分析**:
- GPU 缓存目录权限不足
- 缓存清理后仍无法启动
- `pycoder-electron` 目录创建成功但 Electron 进程立即退出

**修复方案**:
1. 在 `src/main/index.ts` 中检查 `app.whenReady()` 是否正确触发
2. 检查 `dist/main/index.js` 是否与 `src/main/index.ts` 同步
3. 添加更详细的启动日志
4. 尝试以管理员权限运行

**具体代码**:
```typescript
// 在 dist/main/index.js 顶部添加
process.on('uncaughtException', (err) => {
  console.error('[FATAL]', err);
});
```
