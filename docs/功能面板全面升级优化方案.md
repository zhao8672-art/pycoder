## 方案 2: 安装流程稳定性提升

### 2.1 扩展安装统一为异步 + 进度轮询

**当前问题**: `ExtensionsPanel.tsx` 中 `handleInstall()` 是同步阻塞，
而 `SkillsMarketV2.tsx` 有完整的异步进度轮询。两者不一致。

**修复方案**:

1. **后端**: 扩展安装改为异步任务模式
   - `POST /api/extensions/install` 返回 `{task_id: "..."}`
   - 新增 `GET /api/extensions/install/{task_id}/status` 返回安装步骤进度
   - 安装步骤: `downloading → validating → installing → activating → done`

2. **前端**: 复用 SkillsMarketV2 的进度条组件
   - 创建通用 `InstallProgressBar.tsx` 组件
   - ExtensionsPanel 安装时显示 4 步进度条
   - 800ms 轮询任务状态，超时 120s 自动标记失败

### 2.2 断点续传与重试机制

**后端实现** (`pycoder/extensions/manager.py`):

```python
class InstallTask:
    """异步安装任务"""
    task_id: str
    ext_id: str
    status: str  # pending | downloading | validating | installing | activating | done | failed
    progress: float  # 0-100
    step: int  # 当前步骤 (0-4)
    error: str | None
    retry_count: int
    max_retries: int = 3
    created_at: float
    updated_at: float
```

**重试策略**:
- 下载超时 → 重试最多 3 次，指数退避 (1s, 3s, 9s)
- 校验失败 → 直接失败，不重试
- 安装失败 → 重试 1 次
- 激活失败 → 回滚，标记失败

### 2.3 实时状态反馈

**WebSocket 推送** (可选增强):

### 2.5 安装失败的自动恢复机制

```python
def auto_recover_on_fail(task: InstallTask):
    """安装失败自动恢复"""
    if task.step <= 1:  # 下载阶段失败
        # 清理临时文件
        shutil.rmtree(temp_dir, ignore_errors=True)
        task.status = "pending"  # 重置后可重试
    elif task.step == 2:  # 校验失败
        # 保留下载文件，标记为无效
        pass
    elif task.step >= 3:  # 安装/激活阶段失败
        # 执行回滚
        rollback_installation(task.ext_id)
        task.status = "failed"
        task.error = "安装中发生错误，已回滚"
```

### 3.1 修复 `limit=200` 限制（核心修复）

**当前问题**: 
- 前端 `ExtensionsPanel.tsx` `fetchExtensions()` 写死 `limit=200`
- 后端 `search_extensions()` 支持 `limit=200` 但总数据 ~420
- 超过 200 的扩展永远不可见

**修复方案**: 

**方案 A（推荐，1 天）**: 后端实现真正的服务端分页 + 前端改为服务端分页

后端改动 (`pycoder/extensions/marketplace.py`):
```python
async def search_extensions(query="", category="", limit=50, offset=0):
    all_extensions = _load_cache()  # 全量缓存 (已实现)
    results = _filter(all_extensions, query, category)
    paged = results[offset : offset + limit]
    return {
        "extensions": paged,
        "total": len(results),       # 过滤后总数
        "total_all": len(all_extensions),  # 全量总数（新增）
        "offset": offset,
        "limit": limit,
        "has_more": (offset + limit) < len(results),
    }
```
*后端已经支持分页！**只需前端改成分页调用即可**。*

前端改动 (`ExtensionsPanel.tsx`):
```typescript
// 改造前: 全量拉取 200 条，本地切片
const limit = tab === 'recommended' ? 200 : PAGE_SIZE;
```

### 3.4 扩展推荐算法

**实现思路** (轻量级，无需 ML):

```python
def recommend_extensions(user, all_extensions):
    """基于规则的扩展推荐"""
    installed_ids = {e.id for e in user.installed_extensions}
    installed_categories = {e.category for e in user.installed_extensions}
    installed_tags = {t for e in user.installed_extensions for t in e.tags}
    
    scored = []
    for ext in all_extensions:
        if ext.id in installed_ids:
            continue
        score = 0
        # 相同分类 +20
        if ext.category in installed_categories:
            score += 20
        # 相同标签 +5/个
        score += 5 * len(installed_tags & set(ext.tags))
        # 高星奖励
        score += min(ext.stars / 1000, 10)
        scored.append((score, ext))
    
    scored.sort(reverse=True)
    return [ext for _, ext in scored[:50]]
```

## 方案 4: 性能与用户体验优化

### 4.1 加载速度优化

#### 4.1.1 面板懒加载

**当前**: 所有 13 个侧边栏组件在 `Sidebar.tsx` 中通过 `activeView` 条件渲染，
但组件内部 `useEffect` 在首次挂载时立即请求数据。

**优化**:
```typescript

const SkillsMarketV2 = React.lazy(() => import('./skills-v2/SkillsMarketV2'));
const ExtensionsPanel = React.lazy(() => import('./ExtensionsPanel'));

// Sidebar 渲染
{activeView === 'skills' && (
  <React.Suspense fallback={<PanelSkeleton />}>
    <SkillsMarketV2 />
  </React.Suspense>
)}
```

#### 4.1.2 骨架屏

创建 `PanelSkeleton.tsx` 组件，用于所有面板加载时的占位：


### 4.2 异步处理与防卡顿

**当前问题**: 
- ExtensionsPanel 的安装是 `await` 阻塞 → UI 卡住
- 部分面板 useEffect 缺少清理

**优化**:
1. 所有安装/卸载/更新操作改为异步 + loading 状态
2. 长时间操作显示进度条而不是旋转图标
3. 轮询定时器在组件卸载时清理
4. 大量数据渲染使用 `useMemo` + `React.memo`

### 4.3 统一反馈机制

**当前**: 各面板使用不同的消息机制

| 面板 | 消息方式 | 自动消失 | 
|------|---------|---------|
| SkillsMarketV2 | `statusMsg` + `setTimeout(4000)` | ✅ |
| ExtensionsPanel | `statusMsg` + `setTimeout(3000)` | ✅ |
| SettingsPanel | `statusMsg` | ❌ 手动清除 |
| GitPanel | `statusMsg` + `setTimeout(5000)` | ✅ |
| TeamPanel | 内联 `error` | ❌ |

**统一方案**:
```typescript
// PanelContainer 内置 StatusBar
// 支持类型: success / error / info / warning / progress
// 成功/信息: 3s 自动消失
// 错误/警告: 手动关闭 + 自动消失 10s
// 进度: 不自动消失，完成后转为 success 3s 后消失
```

### 4.4 操作流畅度

**优化点**:
1. 搜索防抖统一为 300ms (当前有 300ms/400ms 不一致)
2. 输入建议下拉与搜索框同步（SkillsMarketV2 已实现）
3. 页面切换动画: `transition: all 0.2s ease`
4. 卡片 hover 效果统一
5. 按钮点击反馈: `active` 状态 + 禁止重复点击
